# Generic report writing contract

- Lead with the supported finding, but label model outputs as estimates/sensitivities where appropriate.
- Explain the question, population/geography, period and unit before interpreting a number.
- Keep source observations, assumptions, calculations and unknowns visibly distinct.
- Use a short method note and link every final value to the numbered result key/source record.
- State material limitations near the claim, not only in an appendix.
- Use neutral, original visual styling. Do not import an employer's brand, spokesperson copy, company biography or reuse-license language.
- A human reviews every factual claim and generated chart before the report is final.
